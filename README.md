# Land Use Studio — Beta Feedback

This repository collects **bug reports, feature suggestions, and usability feedback** for the Land Use Studio architectural mapping app.

**[Submit feedback](https://github.com/saifs-cmd/land-use-studio-feedback/issues/new)** · **[Browse existing reports](https://github.com/saifs-cmd/land-use-studio-feedback/issues)**

## How to report a problem

1. Open the **Feedback / Report Issue** button inside Land Use Studio, describe the issue and select **Open GitHub issue**.
2. Sign in to GitHub if needed, check the prefilled title and text, and click **Submit new issue**. The app does not submit automatically.
3. Alternatively, open GitHub Issues and choose a Bug Report or Feature Request template.
4. Include what you expected, what actually happened, and reproduction steps. The app version, browser, and workspace help reproduce the problem.

## Privacy and scope

**This is a public repository.** Reports and attachments may be read by anyone. Do not post CARTO keys, credentials, precise private site locations, client projects, private GIS files, or confidential screenshots. There is no need to share them to report most bugs.

This repository contains feedback templates only, **not the Land Use Studio application code**. The beta website may be unlisted, but this feedback repository is public.

## Report workflow

Reports are triaged here, discussed in issue comments, and closed when addressed. You can follow or subscribe to an issue for updates.
